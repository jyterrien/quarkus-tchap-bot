Ce projet a pour but de mettre en place un sdk java pour connecter un client/bot Matrix.
Il est prévu pour fonctionner avec Tchap.

Il est composé de matrix-client-api matrix-transport-http et matrix-client-core qui proposent une api et son implémentation pour interagir en java avec un serveur Matrix.

A cela s’ajouter une extension Quarkus quarkus-tchap-bot qui permet une intégration dans le framework Quarkus.

Enfin le dossier exemples contient des exemples très simples d’usage de cette extension.
